# TVFloat 新电脑接管验证清单

## A. 安装状态

- [ ] `codex --version` 成功；
- [ ] Codex 已登录；
- [ ] `python --version` 成功；
- [ ] `node --version` 成功；
- [ ] `%LOCALAPPDATA%\TVFloat\migration_install_receipt.json` 存在；
- [ ] 回执中的 `target_root` 存在；
- [ ] 回执中的 `tradingview_mcp_root` 存在；
- [ ] `%LOCALAPPDATA%\TVFloat\market.db` 存在且 SQLite `integrity_check=ok`；
- [ ] `%USERPROFILE%\.codex\skills\tradingview-mcp\SKILL.md` 存在。

## B. TradingView

- [ ] TradingView Desktop 已登录；
- [ ] 通过 `launch_tv_debug.bat` 启动；
- [ ] `http://127.0.0.1:9222/json/version` 返回 debugger URL；
- [ ] 最右侧保留专用监控标签；
- [ ] 专用标签能切换四个完整符号；
- [ ] `ICMARKETS:US500` 没有被替换成 `SPX500`；
- [ ] 自动运行后仍恢复 `BYBIT:BTCUSDT.P`、5 分钟；
- [ ] 其他 TradingView 标签未受影响。

## C. 计划任务

- [ ] `TVFloat-LowToken-Collector` 存在；
- [ ] 状态为 Enabled/Ready；
- [ ] 周一至周五；
- [ ] 每 5 分钟；
- [ ] 24 小时；
- [ ] `MultipleInstancesPolicy=IgnoreNew`；
- [ ] 旧的 `TVFloat-LowToken-Review` 保持禁用；
- [ ] 旧电脑的 Collector 已禁用。

## D. 一次真实冒烟测试

执行：

```powershell
$receipt = Get-Content "$env:LOCALAPPDATA\TVFloat\migration_install_receipt.json" | ConvertFrom-Json
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$($receipt.target_root)\migration\Test-TVFloatMigration.ps1" -RunCollectorSmokeTest
```

验收：

- [ ] 全部显示 `PASS`；
- [ ] 最后显示 `Migration validation passed.`；
- [ ] `%LOCALAPPDATA%\TVFloat\candidate_review_status.json` 有新时间；
- [ ] `%LOCALAPPDATA%\TVFloat\lightweight_runner.log` 无新增致命错误；
- [ ] 数据库最新 K 线时间前进；
- [ ] 悬浮窗最近处理时间更新；
- [ ] 无候选时结果安静结束；
- [ ] 有候选时 AI 复核状态能从待复核转为完成、无信号、失败或超时之一，不永久卡住。

## E. 信号与区间回归检查

- [ ] 橙色矩形可同步为震荡区间；
- [ ] 用户移动/缩放后数据库采用新边界；
- [ ] 用户删除后不会立刻在相同位置重建；
- [ ] 当前仍在区间内时矩形继续向右延伸；
- [ ] 无有效橙框时不允许震荡内部或震荡突破信号；
- [ ] 上下边缘各不足两组独立测试时不画自动区间；
- [ ] 区间边缘触碰能触发悬浮窗和 TradingView 提醒；
- [ ] 正式信号标注锚定信号 K 收盘；
- [ ] 多头绿色、空头红色；
- [ ] 不画信号水平线；
- [ ] 只在最右侧专用标签绘图；
- [ ] Excel 可更新且保留人工复盘列。

## F. 发生故障时优先提供的证据

1. `Get-TVFloatHandoffStatus.ps1` 的完整输出；
2. `%LOCALAPPDATA%\TVFloat\lightweight_runner.log` 最后 100 行；
3. `%LOCALAPPDATA%\TVFloat\candidate_review.log` 最后 100 行；
4. `%LOCALAPPDATA%\TVFloat\candidate_review_status.json`；
5. 计划任务 Last Run Result；
6. TradingView 最右侧标签截图；
7. 失败发生的北京时间和品种。

不要先删除数据库、重装项目、删除全部 TradingView 警报或清空绘图。先通过证据定位问题。
