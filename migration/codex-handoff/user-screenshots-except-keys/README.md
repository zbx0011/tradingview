# 旧会话用户截图与消息映射

来源任务：`tradingview MCP`

Thread ID：`019f8d7b-c4e7-7313-9115-f7c8b5ea8da2`

本目录包含旧会话中用户直接提交的截图，以及截图和用户消息编号、消息 ID、时间戳、原始消息文字之间的映射。

## 范围

- 原始用户截图：71 张。
- 上传截图：67 张。
- 排除截图：4 张，因为画面中包含连接密钥。
- 上下文压缩快照中的重复图片没有重复导出。

## 因密钥排除

- `U0278`：连接窗口，密钥字段部分可见。
- `U0283`：B 电脑连接窗口，完整密钥可见。
- `U0285`：A 电脑主机窗口，完整密钥可见。
- `U0289`：B 电脑连接窗口，完整密钥可见。

排除只针对图片文件；相关用户消息的文字仍存在于完整聊天记录与无截图原始上下文中。

## 映射文件

- `screenshots-message-map.csv`：适合 Excel、人工检查和程序读取，编码为 UTF-8 BOM。
- `screenshots-message-map.jsonl`：适合 AI 和脚本逐条读取。

每一行记录：用户消息编号、消息 ID、时间戳、原始 rollout 行号、同一消息内的图片序号、文件名、MIME、字节数、SHA-256 和对应消息全文。

用户消息编号形如 `U0185`。图片文件名中的 `U0185` 与映射文件中的 `user_message_number=185` 对应。
